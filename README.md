# Hostel Problem Management System

A web-based Hostel Problem Management System designed to simplify the process of reporting, tracking, and resolving hostel-related issues efficiently. The platform enables students to raise complaints digitally while allowing administrators to monitor, manage, and resolve them in an organized manner.

---

# Features

## Student Features
- Register and login securely
- Raise hostel complaints/issues
- Categorize problems (Electrical, Water, WiFi, Cleaning, Furniture, etc.)
- Upload issue descriptions
- Track complaint status in real-time
- View complaint history

## Admin Features
- Admin dashboard for monitoring all complaints
- Update complaint status
- Assign priorities to issues
- Filter complaints based on category or status
- View analytics and issue statistics
- Manage users and hostel records

---

# Problem Statement

In many hostels, issue reporting is still handled manually through wardens or registers. This creates problems such as:
- Delayed issue resolution
- Poor complaint tracking
- Lack of transparency
- Repeated complaints
- Difficulty in managing hostel maintenance

This project digitizes the complete workflow and improves communication between students and hostel administration.

# System Workflow

1. Student logs into the portal
2. Student submits a complaint
3. Complaint gets stored in the database
4. Admin views the issue from dashboard
5. Admin updates status:
   - Pending
   - In Progress
   - Resolved
6. Student can monitor updates in real-time
